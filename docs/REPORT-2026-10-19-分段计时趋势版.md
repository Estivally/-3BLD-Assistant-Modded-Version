## 二、技术要点

### 2.1 分段计时（不改 schema）

- `TimerFragment.smali`：`touchUp` state==0 → `currentPhase=1`、`p1Time=0`、`showSegmentedPhaseOneUi()`、`timer.count2()`
- `touchDown` state==1 且 `currentPhase==1` → `p1Time=timer.getTime()`、`currentPhase=2`、`showSegmentedPhaseTwoUi(...)`
- 保存：`setP1(p1Time)`、`setP2(total - p1Time)`
- 阶段 0.2：`resetSegmentedUi()` 里 `segmentPanel` 可见性改为 `isSegmentedTiming ? 0 : 8`

### 2.2 批量编辑

- `src_java/zd/cornermemory/utils/LxWordStorage.java`：`wordKey` / `builtinWord` / `currentWord` / `hasOverride` / `putWord` / `resetWord`，全 try-catch
- `src_java/zd/cornermemory/ui/LxBatchEditActivity.java`：ListView + 行内 EditText + 内部 `RowAdapter`
- 入口：`dialog_lx_pic_manage.xml` 的 `action_batch_edit` 行，由 `LxBatchImportEntry.attach()` 统一接线
- **没有改 `Dictionary.smali`**：原版 `NormalAdapter` / `LxPicActivity` 本来就按 `SP.getString(code+"_LX", Dictionary.dic.get(code))` 读，覆盖层天然生效

### 2.3 趋势图

- `SegmentTrendActivity`：查 `Cj`（`orderDesc(Date)`）→ 过滤（`p1>0 && p2>=0 && STATUS==0`）→ 取最近 200 条 → JSON → `evaluateJavascript("LX.setData(...)")`
- `assets/segment_trend.html`：零依赖 Canvas；`html.dark` 由 `ThemeManager.isNight()` 决定
- 阶段 0.1：`excluded` 计数 + `applyNote()`；脚注定位修正（`.card` 是 `absolute inset:0`，用 `body.has-note .card { bottom:26px }` 把卡片底部收进来）
- 入口：`CjActivity.onCreate` 末尾插 `SegmentTrendEntry.attach(p0)`

## 四、已知限制

1. **debug 签名**：只有 `~/.android/debug.keystore`；覆盖安装需先卸载同包名旧版。
2. **真机未实测**：只有模拟器。
3. **长按模式停止需两次点击**：与单击模式一致，但首次使用可能困惑，提示文案可再补一句。
4. **`list_item_bgcolor.xml` 2 处 `android:drawable="?attr/app_light_blue"`**：仍是潜在崩溃点（改 `@color` 会丢按方案着色，需另想方案）。
5. **趋势图上限 200 点**：超出只画最近 200 条（数据量大时不做抽稀）。

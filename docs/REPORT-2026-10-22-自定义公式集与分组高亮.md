## 三、自定义公式集格式（给用户看的规范）

一行一个公式，**列序固定**：

```
分组    编码    公式    交换子    起手    [类型]
```

- **分隔符**：Tab、英文逗号、中文逗号都行，自动识别；公式/交换子里含逗号时用 `"` 把整格包起来（Excel 另存 CSV 就是这个行为）。
- **表头**：首行含「编码」「公式」「分组」「交换子」任一关键词时自动跳过。
- **编码**：大写，会自动去掉空格和连字符。
- **交换子**：写成 `setup:[A,B]` 形式（例：`R' D R U':[R' D' R,U']`）；写「空」「-」「无」「Not found.」都当没有。
- **类型列（可选）**：`C`/`角`/`角块` 或 `E`/`棱`/`棱块`。没有这一列时按「导入时手选」或自动推断（分组名含 `UFR`/`角` → 角块，含 `UF`/`棱` → 棱块；3 字母编码看首字母 `J`=角 / `G`=棱）。
- **同一编码多行** = 这个 case 的多条公式（第一行排前面，`★` 选最优时按行选）。
- **编码要求**：角块 3 字母键（如 `JAD`）或 2 字母码（如 `AD`）都可；纯 2 字母码时按导入手选/分组名判类型。
- **编码**：UTF-8（带不带 BOM 都行）；Windows Excel 直接导出的 GBK CSV 也认（UTF-8 严格解码失败会自动回退 GBK）。
- **上限**：文件 2MB / 20000 行。

导入流程：`导入` → 选「角块 / 棱块 / 混合自动」→ 选文件 → 预览「识别到 N 个编码 · M 条公式 · K 个分组（角 a / 棱 b）」，有跳过/重复会一并列出 → 确认后替换旧集并切到自定义源。

浅梦的两份 xlsx（UF 总表 / UFR 总表）按上面格式导出 CSV 即可直接导入，分组会变成 `UF总表` / `UFR总表` 里的分类列。

## 五、本轮修掉的 4 个 bug

1. **CSV 里交换子带逗号被切成多列** —— `splitLine` 只按单字符切。改成 `splitCsv`（认引号）+ `normalize`（列数 >5 时按「末列是否像类型/是否像起手」把多出来的列并回交换子）。症状是 meta 显示 `交换子 R' D R U':[R' D' R` + `起手 U']`。
2. **自定义集第一行永远挂「荐」徽章** —— 自定义集 `rec` 传 0，而 0 是「官方推荐」。改传 `-1`。
3. **冷启动 818 联想词全空** —— `am start` 深链时 `Dictionary.dic` 还没初始化。加 `setWordWithRetry`：显示为空则 400ms 后再补一次（换卡就放弃）。
4. **切分类后分组筛选残留导致空队列** —— 分组是角/棱各自的概念，从「角块 + R.D.」切到「棱块」时队列为空、混合也只剩角块（看起来像角棱交替失效）。加 `normalizeGroup()`：分组不属于当前分类就回到「全部」并落盘；分组 chips 也按分类过滤，只显示该分类下的分组。

- 自定义集只存一份（导入即替换）；多套集/多套命名还没做。
- 818「查找定位」「我的最优清单页」仍未做（原阶段二剩余）。
- 自定义集解析后不做魔方合法性校验（内置/浅梦资产是离线模拟器逐条验过的，用户自己导入的公式只做格式校验）。

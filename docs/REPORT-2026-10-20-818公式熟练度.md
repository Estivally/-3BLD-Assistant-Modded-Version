## 二、818 的数据口径（关键结论）

| 项 | 结论 |
|---|---|
| 总数 | 角块 **378** + 棱块 **440** = 818 |
| 卡片身份 | **3 字母键**（如 `JAD`），不是「末尾两字母配对」 |

| 联想词 | `Dictionary.dic` 576 个两字母键，818 个配对**全部命中**（0 缺失）→ `LxWordStorage.currentWord(key.substring(1))`，尊重用户自定义覆盖 |

### 精简资产

`D:\Program\dsh\rebuild\make_alg818_assets.py`（幂等 + 自检）读 5 个 JSON，只取 `J*`/`G*` 键，输出 `src/assets/alg818.txt`：

```
TYPE \t KEY \t REC \t ALG1 \t ALG2 ...      (TYPE: C=角块 / E=棱块, REC=-1 表示无推荐)
```

结果：**818 行（角 378 / 棱 440），50804 条算法，1.68 MB**（APK 内压缩后 345 KB）。

自检项：总行数 / 角棱数量 / 键唯一 / **按类型**配对唯一 / 算法列表与原始库逐条相等 / REC 下标命中的算法 == nightmare 值 / 回读逐字段一致。

## 四、调度规则（沿用联想词 SRS，全部换 `alg818_*` 前缀）

| 评分 | box | 下次复习 | 副作用 |
|---|---|---|---|
| 忘记 | 归 1 | +10 分钟 | 非新卡 laps+1，且**本会话队尾再排一次**（每卡限 1 次） |
| 模糊 | 不变（<1 归 1） | +max(1h, 当前间隔/2) | 不升不降 |
| 记得 | +1（上限 6） | +1 / 3 / 7 / 15 / 30 / 60 天 | reps+1 |

- 队列 = **到期复习（due 升序）+ 新卡**；新卡每日额度 20；混合 = 角块 + 棱块合并后 shuffle。
- 跨天用 `yyyyMMdd` 整数比对 `alg818_day` 清零 `day_new` / `day_rev`。
- 空态：熟练(≥4) / 熟悉(≥2) / 生疏(=1) / 未学(=0) 四档统计 + 「再学 N 个」按钮——**手动加餐不受每日额度限制**。

### 验证中发现并修正的两处

1. **「再学」按钮在当日额度用尽后消失**：`emptyMore = min(NEW_BATCH, min(allowance, fresh))` 在 allowance=0 时得 0 → 改为 `min(NEW_BATCH, fresh)`（手动加餐不受额度限制，与 `LxStudyActivity` 一致）。
2. **取消星标写空串**：`sp.put(K_BEST+key, "")` 会留下 818 个空键 → 改为 `sp.remove(K_BEST+key)`（真实 `SPUtils` 有 `remove(String)`）。

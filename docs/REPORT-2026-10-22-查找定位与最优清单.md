## 2. 查找规则

| 输入 | 判定依据 | 行为 |
|---|---|---|
| `AD` | 2 字母 = 展示码 | 当前源里按 code 找；撞名（角棱同码）时优先当前分类；没找到先试浅梦、再试自定义（若有） |
| `JAD` | 3 字母 = 内置键 | 自动切到内置集再找 |
| `qCAD` | `q` + 类型 + 码 | 切浅梦，按 `CAD` 找 |
| `cAD` | `c` + 类型 + 码 | 切自定义（无自定义集则跳过） |
| `ZZZ` | 找不到 | Toast「没找到编码 ZZZ」，日志 `查找未命中` |

定位成功后的动作统一：清分组筛选 → 切到该 case 所属分类 → 队列里有就设游标（`定位到 <key> index=<i>`），没有就插到队首（`补入 <key> 到队首`）。

## 3. 我的最优清单

- 数据源就是 SP 的 `alg818_best_<caseKey>`（value = 公式），按前缀分源：内置 = 3 字母键（`JWP`）、浅梦 = `q` + 类型 + 2 字母码（`qCAD`）、自定义 = `c` + 前缀。
- 排序：内置 → 浅梦 → 自定义，同源内按编码。
- 每行三行文字：`源 · 类型  编码  联想词` / 等宽公式 / `N 步`，右侧 `×`。
- 点行 → `target_code` 跳回 818，那边 `applyTarget` → `focusCase` 定位。
- 空态：隐藏统计行，只留「还没有标星的公式 / 在 818 卡片里点 ★ 选一条最优，这里就会汇总」。

## 5. 本轮修掉的问题

1. **空态仍显示「共 0 条 · 点一行回到那张卡」**（误导）→ 空态隐藏该行。
2. **内置集在清单里只显示 2 字母码**（`AD`）与卡片上的 3 字母键（`JAD`）不一致 → 内置显示完整键，联想词仍按末两位查。
3. **查找只能在同一公式源内命中**：输入 `JAD` 而当前在浅梦源时会报「没找到」→ 按写法猜源并自动切换重试。

## 6. 踩坑（写进 MEMORY）

- 点 `☆` 要用 dump 出来的 `bounds` **中心**；点 bounds 左上角那一像素会 miss（表现为「点了没反应、没有日志」）。
- 查找弹窗弹出软键盘后整体上移：`查找` 按钮从 `[799,1132]-[975,1281]` 移到 `[799,789]-[975,938]`，先 dump 再点。
- `uiautomator dump` 失败会保留旧文件 → 一律先 `rm -f /sdcard/u.xml`。

## 7. 遗留

- 最优清单**不显示自定义集的分组**（SP 里只存了公式，没存分组）。
- 最优清单**没有排序切换**（固定 内置→浅梦→自定义 + 编码序）。
- 查找的跨源切换靠「长度 + 前缀」猜，不是全源搜索；2 字母码在三个源里都存在时只认第一个命中的源。
- 版本号仍 6.2.2(115)、仍 debug 签名（用户此前说先不用管）。

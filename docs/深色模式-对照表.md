## 六、英文覆盖层（values-en-night）

原版就有 `res/values-en/`：它自己重定义了 `AppTheme`（parent `Base.Theme.AppCompat.Light`）和 21 个颜色，用的是**旧 Material 默认色**（`#3f51b5` / `#ff4081`）。
Android 选资源时**语言优先于夜间模式**，所以英文设备上 `values-en` 会盖掉 `values-night` → 出现「黑字黑底」。因此补了一层 `values-en-night/`。

| 资源名 | values-en（浅） | values-en-night（暗） |
|---|---|---|
| `bag` | `#f8f9fb` | `#121417` |
| `bg_color` | `#f8f9fb` | `#121417` |
| `black` | `#000000` | `#e8eaed` |
| `cj_right_color` | `#828282` | `#9aa4b2` |
| `colorAccent` | `#ff4081` | `#ff80ab` |
| `colorPrimary` | `#3f51b5` | `#7986cb` |
| `colorPrimaryDark` | `#303f9f` | `#5c6bc0` |
| `green_text` | `#00cc00` | `#4ade80` |
| `grey` | `#222222` | `#3a4046` |
| `line` | `#e5e5e5` | `#2b3138` |

同时 `values-en-night/styles.xml` 把英文层 AppTheme 的 parent 换成 `Base.Theme.AppCompat`（浅色 `Base.Theme.AppCompat.Light` 的暗色对应物），**结构不变、只换明暗**。

> 目录名必须是 `values-en-night`（语言在前、night 在后）——
> 写成 `values-night-en` 会被 aapt2 判为 `invalid configuration`。

## 七、有意保持不变的

| 类别 | 例子 | 为什么不动 |
|---|---|---|
| 魔方贴纸色 | `cube_fill_{white,red,blue,green,orange,yellow}` | 语义色不是界面色；白面在暗色下也该是白的 |
| 品牌 / 语义实色 | `#6366f1` `#4f46e5` `#059669` `#ef4444` `#f97316` | 中深饱和色，暗底上照样能看 |
| 半透明叠加 | `#336366f1` `#1a6366f1` `#22ef4444` … | 品牌色半透明蒙层，两套主题下语义一致 |
| 阴影 | `#140f172a` `#7a0f172a` `#080f172a` … | 阴影本来就该是黑的 |
| 遮罩 | `#80000000` `#cc000000` `#40000000` | 弹窗压暗层 |

## 四、已知限制与风险

1. **WebView 深色双保险**：`wrap()` 改 uiMode 后 WebView 可能不跟系统，因此保留了 `html.app-dark` 类兜底（由 Java 在加载完成后注入）。若未来改为系统 WebView 自动适配，可去掉兜底。
2. **`list_item_bgcolor.xml` 潜在崩溃点**：仍有 2 处 `android:drawable="?attr/app_light_blue"`，当前因解析为颜色而未崩；若某 overlay 把 `app_light_blue` 改成引用 drawable 会立即崩溃。建议后续统一改为 `@color` 引用。
3. **Anki 新格式不支持**：`.anki21b`（zstd 压缩）无法解析，UI 已抛 `NewAnkiFormatException` 提示用户导出时勾选「支持旧版 Anki」。
4. **真机未实测**：`adb devices` 仅见 emulator-5554。深色取值基于设计推导，浅色可保证逐字节恒等。
5. **debug 签名**：正式发布前需更换正式 keystore。

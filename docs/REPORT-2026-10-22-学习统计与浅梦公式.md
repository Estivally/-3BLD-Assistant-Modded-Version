# 学习统计 + 每日额度 + 浅梦公式源 —— 实施报告（2026-10-22）

## 一、需求

用户在这一轮提出三件事（原话要点）：

1. **每日复习量可设置** —— 「每天学多少能自己定」（新卡、复习、每批三个额度）。
2. **总体记忆情况** —— 「想看到整体记得怎么样」（连续天数、近 7 天训练量、未来 7 天到期、档位分布、薄弱 Top10）。
3. **818 支持自己的公式集** —— 提供了两份「浅梦」818 公式 xlsx，要求「818 公式熟练度能用自己的公式训练」。

两个学习页的接入（`LxStudyActivity` / `Alg818Activity`）：

- `buildQueue` 用 `StudyPrefs.revLimit / newLimit` 取代写死的 20 / 不限；每批数量用 `StudyPrefs.batch`。
- `grade()` 开头调 `StudyStats.record(...)` 记当日统计。
- 加 `bindToolbar()`（标题 / 返回 / ⚙）、`dataVer` + `onResume` 版本变化即重建队列、`applyTarget(Intent)` 处理统计页薄弱榜的 `target_code`。
- `LxStudyActivity` 额外修了**冷启动竞态**：词典异步加载时原先直接 `finish()`，现改为每 250ms 重试、最多 12 次，并在 `onResume` 里跳过「编码表还空」的情况。

### 2.2 阶段二：浅梦公式源

| 文件 | 作用 |
| --- | --- |
| `src/assets/alg818_qm.txt` | 818 行 / 71,918 B。格式 `TYPE\tKEY\tCAT\tHAND\tCOMM\tNOTE\tALG\tALT\tALT_COMM` |
| `tools/alg818_qm_import.py` | 从两份 xlsx 生成上面的资产（798 行，幂等，含 6 道自检） |
| `src_java/.../Alg818Activity.java` | 公式源切换（内置 / 浅梦），`Case` 扩展 `code/cat/hand/comm/note` |
| `src/res/layout/activity_alg818.xml` | 顶部「公式源」行：`内置` / `浅梦` 两枚 chip |
| `src/res/values/strings.xml` | 新增 6 条 `alg818_src_* / alg818_qm_*` 文案 |

**关键设计决策：两套 case 身份，互不映射。**
浅梦的棱块缓冲是 UF，App 内置集是 UR（`edgePosToCode.json` 里 UR=G、UF=A）。同一个 3 字母键在两边指的**不是同一个物理 case**，全表只有 40 个棱块 case 真正重合。所以：

- 内置源：卡片用 3 字母键（JWP、GAC…），进度键 `alg818_b_<KEY>`。
- 浅梦源：卡片用浅梦自己的 2 字母码（AD、GC…），进度键 `alg818_b_q<CODE>`、最优公式 `alg818_best_q<CODE>`。
- 两边进度完全独立，切源不串味；不伪造「浅梦公式解内置键」的映射。
- 浅梦码反推：资产 KEY = `"G" + f(浅梦 code)`，f 是自反对合（A↔G、B↔H），故 `code = f(KEY.substring(1))`。实测棱块 818 条 code 无一条含 A/B、80 条含 G/H、无重复。

卡片背面在浅梦源下多显示「交换子 / 起手 / 备注」，统计页薄弱榜对 `q` 前缀码显示为「浅梦 XX」。

### 2.3 导出落地位置（本轮修的坑）

初版导出写到 `getExternalFilesDir("study")`，分享面板读缩略图时抛
`SecurityException: ... requires the provider be exported, or grantUriPermission()`，而且 API 30 的
文件选择器看不到 `Android/data/`，导入时根本选不到自己导出的文件。

改为：API 29+ 用 MediaStore 写到公共 **「下载/三盲助手/」**（`RELATIVE_PATH=Download/三盲助手`），
低于 29 回退到私有目录 + FileProvider；分享 Intent 补 `setClipData(ClipData.newRawUri(...))`，
否则 ChooserActivity 拿不到读权限。

## 五、已知问题与未做项

1. **浅梦棱块 400/440 是形式重标号**：公式解的是浅梦 UF 缓冲 case，而卡片用浅梦自己的码，所以口径自洽；但**不能**把浅梦公式套到内置 3 字母键上。已按「两套身份」隔离。
2. **818 页冷启动联想词可能为空**：`Dictionary.dic` 由主界面初始化，用 `am start` 直接深链进 818 页时取不到词（卡片正面空白）。正常从「记忆」tab 进入不受影响；联想词页已加重试，818 页未加。
3. **导入是全量覆盖**：不做合并、不做按时间戳取新。导入前弹确认框显示「将覆盖 N 条」。
4. 原计划里的 **阶段三**（联想词反向卡、卡片内改词/换图）和 **阶段二的「818 查找定位 / 我的最优清单页」** 本轮未做。
5. 版本号仍是 `6.2.2 (115)`、仍是 debug 签名 —— 用户此前说「先不用管这些」。

## 六、踩过的坑（供后续参考）

- `adb install -r` 的**增量安装**会报 Success 但没换包，必须 `--no-incremental`；核对要用 `aapt2 dump xmltree` 或 `dumpsys package | grep lastUpdateTime`。
- `uiautomator dump` 在「记忆」tab 和首页持续 `could not get idle state.`，绕法是直接 `am start` 目标页再 dump；判定成功用 `[ -f /sdcard/x.xml ]`，别信 `ls` 的报错。
- dump 出来的**底部 tab** 坐标比实际可点位置低约 100px；ScrollView 内容区坐标是准的，一律取 bounds 中心。
- 弹窗里键盘弹出后对话框会上移，OK 按钮坐标要重新 dump 再点。
- DocumentsUI 的列表行 `input tap` 常常点不动，`KEYCODE_DPAD_DOWN` + `KEYCODE_ENTER` 反而稳。
- PowerShell 里 `bash -lc "... $? ..."` 会被 PowerShell 先展开 `$?`，要用单引号包脚本。
- 中途 kill `install_java_smali.sh` 会在 `src/smali` 留下没登记的 `$N.smali`，下次安装误报「同名类冲突」，把文件名补进 `tmp/java_owned.txt` 即可。

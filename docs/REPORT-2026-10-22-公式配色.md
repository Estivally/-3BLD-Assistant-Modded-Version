## 1. 需求（用户原话 m06252）

> 对于交换子的高亮参考俩文件，里面的公式文字有具体的颜色，颜色照搬，记得添加其他的颜色，不止针对交换子，请忽略AG等编码本身高亮

参考文件：
- `浅梦's 棱块UF分类公式集 202602版.xlsx`
- `浅梦's 角块UFR分类公式集 202602版.xlsx`

要点：①颜色**照搬** xlsx，不自己发明；②范围是整条公式（不只交换子那一段）；③编码列/编码文字的橙色高亮**不要**搬。

## 2. 图例（xlsx「说明」B4 原文 → 角色码）

| 颜色 | ARGB | 含义 | 角色码 |
| --- | --- | --- | --- |
| 红 | `FFFF0000` | 交换步骤部分（A / A'） | 1 `ROLE_EXCH` |
| 紫 | `FF7030A0` | 直达层部分 | 2 `ROLE_LAYER` |
| 蓝 | `FF00B0F0` | 消步合并部分（与 setup 撤销合并的边界步） | 3 `ROLE_MERGE` |
| 黑 | `FF000000` | setup 部分（含收尾） | 0 `ROLE_SETUP` |
| 橙 | `FFE26B0A` | 提示；编码列橙色 = 备选第一条为优解 | **忽略** |

拆解规则：`C:[A,B] = C A B A' B' C'`；「4步双空穴」红色是交换子部分。

颜色是**按角色分段**、不是按字母：同一个字母在不同 case 里可能是黑、可能是紫（直达层的单层转即使出现在 setup 里也标紫）。

### 生成器改动（`tools/alg818_qm_import.py`，幂等，`--check` 只自检）

- 新增 `from openpyxl.cell.rich_text import CellRichText, TextBlock`；

- `_run_mask(v)`：富文本 → 原文 + 掩码（非 TextBlock 段记 setup）；
- `normalize_with_mask(raw, mask)`：按 `norm_text` 同一套规则（撇号翻译、全角/制表/换行→空格、空白折叠、去首尾）**逐字符搬掩码**，保证掩码与最终文本严格对齐；
- `parse_colors(path, report)`：除「说明」「编码」外所有 sheet 的「公式」「备选」两列；统计 cells / rich / plain / masked；
- 输出第 10/11 字段 `m_alg` / `m_alt`；长度不符记 problem 并清空；字段数断言 `{9}` → `{11}`。

## 4. 客户端实现

### 新类 `src_java/zd/cornermemory/ui/AlgColor.java`

| 成员 | 作用 |
| --- | --- |
| `ROLE_SETUP/EXCH/LAYER/MERGE` | 角色码 0/1/2/3 |
| `static final class Palette {int exch, layer, merge; int of(int role)}` | 三色 + 角色取色（role 0 返回 0 = 不上色） |
| `palette(Context)` | `ThemeManager.isNight()` 决定深浅：浅色用 xlsx 原色 `FF0000 / 7030A0 / 00B0F0`，深色提亮 `FF6B6B / C79BF0 / 4FC3F7` |
| `decorate(alg, mask, comm, p)` | 有掩码且长度一致 → `decorateMasked`；否则 `maskFromComm` |
| `decorateMasked(text, mask, p)` | 同角色连续段打 `ForegroundColorSpan`，role 0 不打（继承 TextView 文字色 → 深色主题自动变浅色） |
| `maskFromComm(alg, comm)` | `splitComm` 解析 `C:[A,B]` → setup/A/B/A'/B' 角色，再在 alg token 上贪心对齐回填掩码 |
| `decorateComm(text, p)` / `decorateCommWithin(text, comm, p)` | 交换子文本上色（`[` 后逗号前=红、逗号后=紫、括号/冒号=0） |
| `maskForCommText(s)` | 交换子字符串自身的逐字符掩码 |

## 7. 坑（本轮新增）

1. **`job_kill` 杀掉 pwsh 包装进程后，bash 子进程仍在继续拷贝 smali**：`AlgColor.smali`/`AlgColor$Palette.smali` 进了 `src/smali` 但没登记进 `tmp/java_owned.txt`，下一次 `install_java_smali.sh` 误报「与 App 原有类同名冲突」并中止。**正解**：把两行补进 `tmp/java_owned.txt`（171→173 行），不要用 `JAVA_SMALI_TAKEOVER=1` 硬闯。
2. **`uiautomator dump` 在有动画的页面（计时页）会报 `could not get idle state`，且返回的是旧窗口的层级**（本轮多次据此误判页面）；验证一律以 `screencap` 截图为准。
3. **底部 tab 实际 x 坐标**：记忆 132 / 读码 326 / 打乱 541 / **计时 784** / 其他 985（y≈1930）。按 x=756 会点进「计时」并启动计时器（本轮误触两次，均用 `KEYCODE_BACK` 取消，未写库）。
4. **查找键规则**：浅梦源内部键是 `q + 类型字母 + 2 字母码`（如 `qCAR`），内置源是 3 字母键（`JAR`），自定义是 `c + 类型 + 码`；输 `qAR` 会「查找未命中」，要输 `qCAR`。
5. `apktool.yml` 里版本号是 `versionCode: 117`（无引号），按带引号替换不会命中。

## 8. 遗留

- 10 条 case（`Others`/`M4` 里的简单公式）在 xlsx 里就是纯文本格，无掩码 → 全默认色；如需上色可后续按交换子推导（这些 case 大多无交换子，推导不出）。
- 备选（ALT）公式只有在 xlsx「备选」列是富文本时才有掩码，其余为默认色。
- 深色主题的三色变体（`FF6B6B/C79BF0/4FC3F7`）未在模拟器验证。
- 编码列橙色（优解提示）按需求**未**实现为文字高亮，仍由「荐」徽章表达。

## 3. 实现

### 3.1 数据模型（`LxBatchEditActivity.Row`）

| 字段 | 含义 |
|---|---|
| `String picPath` | 当前**已落盘**的自定义图路径（null = 用内置图） |
| `byte[] pendingPic` | 刚选中、还没保存的图片字节（仅内存，预览用） |
| `boolean picCleared` | 已标记清除（保存时删 SP 键） |
| `boolean picDirty` | 本行图片有改动，保存时需要提交 |

### 3.2 保存链路

`save()` 在原有「写词 / 恢复词」之后追加：

```java
if (r.picDirty) {
    if (commitPic(r)) changed++;
    r.picDirty = false; r.pendingPic = null; r.picCleared = false;
}
```

`commitPic(Row)`：

1. `picCleared` → `SPUtils.remove(code + "_LXPIC")`，并 `deleteOldPic(旧路径)`；
2. 有 `pendingPic` → `LxPicStorageUtils.saveCustomImageFromBytes(ctx, code, bytes)`（落到 `files/lx_pic_custom/<code>_<ts>.jpg`）→ 写 `SPUtils.put(code + "_LXPIC", 新路径)` → 旧路径不同则删旧图；
3. 只删**托管目录内**的旧图（`LxPicStorageUtils.isManagedLocalPath`），用户自己选的图库外部路径一律不动。

`changed > 0` 时照旧发 `lx_asset_updated` 广播，联想页 / 记忆页下次刷新即可看到新图。

### 3.3 选图

- `pickImage()`：`Intent.ACTION_OPEN_DOCUMENT` + `CATEGORY_OPENABLE` + `image/*`，`REQ_PIC = 4501`，记录 `pickTargetCode`。
- `onActivityResult`：读字节（上限 8MB）→ 挂到 `pendingPic` → `picPath = null`、`picDirty = true` → 刷新列表 + Toast。
- Adapter 的 `bindImage()` 优先画 `pendingPic`（`decodeBytesThumb`，两段解码 target 72dp），否则画 `picPath` 的自定义图，再否则画 `Dictionary.pic` 的内置图 —— 所以「换图后未保存」也能立刻在列表里看到效果。

### 3.4 恢复默认图

- `confirmResetPics()`：先统计**当前可见行**里有自定义图的数量，0 则 Toast「当前列表里没有自定义图」；否则弹确认框「把当前列表里 N 行的自定义图恢复成内置图（点「保存修改」后生效），确定吗？」
- `resetPicsVisible()`：把这些行置 `picCleared/picDirty` 并清 `picPath/pendingPic`，刷新列表 + Toast 数量；真正落盘仍等「保存修改」。
- 与「恢复默认词」互不影响：一个只动词，一个只动图。

## 6. 经验 / 坑

1. **uiautomator dump 的 bounds 与真实可点位置有偏差**（本机约 60–100px，且方向不固定）。系统文件选择器（DocumentsUI）里按 dump 坐标点击两次都没命中，最后用 `input keyevent KEYCODE_DPAD_DOWN` + `KEYCODE_ENTER` 一次成功 —— **第三方 App 的列表页优先用 DPAD 导航，别猜坐标**。
2. 底部按钮文案变长后，按 dump 的 x 中心点容易点到隔壁按钮（`恢复默认图` 与 `保存修改` 只差约 30px），点击前先按截图量一遍。
3. 缩略图点击必须给 `clickable="true"`，否则 `ImageView` 不接收点击，监听器形同虚设。
4. `commitPic` 里删旧图要限定托管目录：用户从图库选的图可能是别人也在用的文件，不能随便删。

## 7. 遗留

- 签名仍是 Android Debug（换正式 keystore 的事一直挂着）。
- 「恢复默认图」只作用于**当前列表（搜索过滤后的可见行）**；若用户搜索后再点，只会清掉过滤结果里的图 —— 已在文案里写「当前列表里 N 行」，如需全量应清空搜索框。
- 批量导入页（`LxBatchImportActivity`）与单编码换图页仍是各自独立逻辑，没有复用 `commitPic`。

## 3. 关键设计

### 3.1 多套公式集存储

- 索引：SP 键 `alg818_sets_index`（JSON 数组，字段 `id/name/type/cases/corner/edge/groups/bytes/at`）；当前套：`alg818_cur_set`。
- 正文：`files/alg818_sets/<id>.txt`（原样保存用户导入的文本，装载时再解析，便于以后改解析规则不丢数据）。
- `id = "s" + System.currentTimeMillis()`；名称空 → 「未命名公式集」，超 24 字截断。
- 旧单套 `files/alg818_custom.txt` 首次访问时迁移成名为「我的公式集」的一套，原文件改名 `legacy-<ts>.bak` 归档（不删）。
- 上限 20 套：`create()` 先查 `loadIndex().length() >= 20` 直接拒绝并 Toast。
- 自定义源的分组筛选键带上套 id（`alg818_group_custom_<id>`），切套不串分组。

### 3.2 薄弱榜 ↔ 我的最优 打通

- 薄弱行尾部读 `alg818_best_<caseKey>`：有值就显示 `★ 最优 N 步`（N = 公式 token 数），点行照旧跳 818 并定位。
- 最优公式选中时同时写 `alg818_bgrp_<caseKey>`（存当时的分组名），供清单页显示分组——最优存储仍然只有 `alg818_best_` 一份，分组只是旁注。

### 3.3 浅梦说明页

- 资产 `src/assets/qm_readme.txt`（9,805 B / 122 行，由 `tools/qm_readme_import.py` 从两份 xlsx 的 `说明` sheet + 各分页首个「备注」单元格生成）。
- 行协议：`#V1` 头 + 每行 `[S] 标题` / `[G] 分页名` / `[P] 段落` / `[I] 条目` / `[L] 链接`。
- 内容：8 个标题、16 个分页（角 Base/DU/UU/R.U./R.D./R.F(B).R./Others/BT；棱 U8/E8/S8/M8/E4/S4/M4/Others）、2 条在线文档链接（可点）。

### 3.4 查找全源

按 `当前源 → 内置 → 浅梦 → 自定义` 顺序逐个切源 `findCase`，命中就 `focusCase`；全不中切回原源并提示。自定义源不存在时跳过。

## 5. 本轮修掉的 bug（7 个）

1. **编译**：`StudyStatsActivity` 用了 `SPUtils` 但没 import → 补 `import zd.cornermemory.utils.SPUtils;`。
2. **无限递归崩溃**：`Alg818CustomSet.list()` → `migrateLegacy()` → `create()` → `list()`，一进「公式集管理」就 `StackOverflowError`。拆成公开 `create()`（检查 + 上限 + 委托）与私有 `createInternal()`（写文件 + 写索引 + 就地返回 `SetInfo`）。
3. **导入后落在空 tab**：`applyImported` 写死 `setCategory(CAT_CORNER)`，棱块专用集会显示「这一类练完了」。新增 `autoCategory(prefer)`（偏好分类有卡就保持，否则回落有卡的一边），用在 `switchSrc` / 切套重载 / `applyImported` 三处。
4. **清单伪条目**：排序键 `alg818_best_order` 被 `alg818_best_` 前缀扫描当成一条最优公式（显示成「内置 · 棱块 order」）。排序键改名 `alg818_bl_order`，启动时迁移并删除旧键。
5. **清单分组文案**：只有浅梦/自定义显示分组，空分组写「未分组」，内置集不显示。
6. **重命名按钮文案**：原来借用 `alg818_import_ok`（显示「导入」）→ 新增 `alg818_set_rename_ok`=保存。
7. **切套无反应**：在浅梦/内置源下点「公式集管理」里的某一套毫无反应（重载分支只在自定义源时执行）→ 改为只要存在自定义套就强制切到自定义源并重新装载。

## 6. 遗留

- 仍是 **debug 签名**；上架/长期使用需要换正式 keystore（用户此前说先不用管）。
- 公式集上限 20 套、单文件上限 2 MB / 20000 行。
- 公式合法性只做「可疑记号」提示（不阻断），不做魔方求解校验。
- 混合 tab 的**到期复习段**仍按到期时间排序（不交替），只有新卡段交替——设计如此。
- 自定义集导入仍是「整份替换单套」，不支持逐条增删。

## 7. 踩坑

- **程序化 AlertDialog + 软键盘**：弹键盘后对话框整体上移（本例重命名弹窗按钮从 y1206 移到 y863），点按钮前必须重新 dump 坐标，否则会点到「取消」。
- **`adb shell input text` 不支持中文**，测试改名只能用 ASCII。
- **DocumentsUI**：列表行 `input tap` 常无效，用 `KEYCODE_DPAD_DOWN` + `KEYCODE_ENTER`；列表按修改时间倒序，push 的新文件排最前。
- 跑任何打印中文/符号的 python 必须 `PYTHONIOENCODING=utf-8 PYTHONUTF8=1`，否则 GBK 控制台在 `⚙` 上抛 `UnicodeEncodeError`。
- `verify_rebuild.py` 必须在 `D:\Program\dsh\rebuild` 下运行（它按相对路径读 `original.apk`）。

## 8. 追加（同日 15:30）：混合 tab 改成随机练习

需求：「混合可以改成当前所学的公式的随机练习」。两处口径已确认：抽题池 = **只抽学过的（box>0）**，一张都没有时退回全部；三档评分**照常写进 SRS**。

### 8.1 行为

| 项 | 角块 / 棱块 tab（不变） | 混合 tab（新） |
|---|---|---|
| 选卡 | 到期复习（按 dueAt）+ 每日新卡额度 | 从「已学（box>0）」里洗牌，不看 dueAt、不受额度限制 |
| 池子 | 该分类全部 | 已学卡（角+棱合并）；一张都没学过时退回全部 |
| 一轮内重复 | 忘记会本会话再排一次 | 不重复，忘记的交给 SRS（10 分钟后再来） |
| 进度文案 | `待复习 N · 新卡 M` | `角 X · 棱 Y`（剩余张数） |
| 练完 | `这一批练完了` + `再学 N 个新卡` | `这一批练完了` + `再抽一批`（重新洗牌） |

- 分组筛选在混合下同样生效（先按分组过滤再洗牌）。
- 洗牌用 `Collections.shuffle(pool, new Random(System.nanoTime()))`，每次进 tab / 点「再抽一批」都重洗。
- 评分链路完全不变（`StudyStats.record` + box/due/reps/laps 照写），只是不再受调度限制。

### 8.2 实测

- 自定义集（4 张，2 张学过）：`随机练习 2 张（角 2 / 棱 0，池=已学 2 张）`。
- 浅梦（818 张，14 张学过）：`随机练习 14 张（角 11 / 棱 3，池=已学 14 张）`，评分顺序 `qCAG → qCAR → qCDR → qECN → qCDX`（非编码序、角棱混排）。
- 进度 `本次 5 / 14`、`角 7 · 棱 2`；全评完 `本次 14 / 14` 且**队列长度不再增长**（忘记不再重复入队）。
- 空态：`🎯 这一批练完了` / `熟练 0 · 熟悉 0 · 生疏 14 · 未学 804` / `再抽一批`；点击后 `本次 0 / 14`，重新洗牌。
- 回归：角块 tab 仍是 SRS（`队列 corner due=0 new=5`）。

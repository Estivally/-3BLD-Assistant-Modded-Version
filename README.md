# 三盲助手 · 定制重建版

一个三阶盲拧训练 App 的反编译重建与功能增补工程。原 App 为 `zd.cornermemory`（三盲助手 6.2.2 / versionCode 115，targetSdk 33 / minSdk 21），本仓库记录**自己新写的 Java 代码、构建脚本、数据转换工具、资源补丁与开发文档**，当前版本 `6.3.0 (116)`。

> 仓库只放源码与文档，不含成品 APK、原版反编译全量产物、图片素材（体积原因，见 `.gitignore`）。

## 1. 功能总览

### 计时与成绩
| 功能 | 说明 |
| --- | --- |
| 分段计时 | 计时页三段手势：第 1 次点击进入**记忆阶段**，第 2 次点击进入**复原阶段**，第 3 次点击停止并保存。P1（记忆 ms）/ P2（复原 ms）随成绩入库 |
| 分段趋势 | 成绩列表右上角「分段趋势」：WebView + 纯 Canvas 双折线 + 面积，零第三方库；只统计 `STATUS == 0` 的有效成绩，DNF / +2 只计数并以脚注提示 |
| 计时设置提示 | 设置页给出分段面板的操作说明文案 |

### 联想词（编码联想记忆）
| 功能 | 说明 |
| --- | --- |
| 联想词 SRS 学习页 | 类 Anki 间隔重复：三档评分（忘记 / 模糊 / 记得），到期队列 + 每日新卡额度，7 档间隔（0 / 1 / 3 / 7 / 15 / 30 / 60 天），忘记的卡片本场再排一次、10 分钟后重新到期 |
| 正向 / 反向卡 | 正向「看码猜词」、反向「看词猜码」一键切换，方向持久化 |
| 卡内编辑 | 卡片右上 ✎：改联想词、换自定义图、恢复默认（复用 `LxPicStorageUtils` 落盘） |
| 批量编辑 | 列表 + 行内输入框批量改词，支持按编码定位、单条重置 |
| 批量导入 | CSV / TSV 批量导入联想词与自定义图 |

### 818 公式熟练度
| 功能 | 说明 |
| --- | --- |
| 内置 818 集 | 角 378 + 棱 440，卡片身份是 3 字母键（缓冲 UFR / UR） |

| 混合随机练习 | 混合 tab 改为从**已学过**的公式里随机抽题（无已学则退回全部），评完可「再抽一批」 |

| 公式高亮 | 把交换子展开后在公式里定位最长公共片段（≥ 3 token）高亮，meta 行同步高亮交换子原文 |
| 查找定位 | 按编码查找，跨内置 / 浅梦 / 自定义三源逐个尝试并定位到卡片 |

## 3. 构建链

原 App 走的是「反编译 → 改 smali/资源 → 重打包」路线，新增代码用 Java 写、编译成 dex 后再 baksmali 回灌：

```
src_java/*.java
   │  build_java.sh        javac(-source 8) → d8 --min-api 21 → baksmali
   ▼
tmp/smali_out/            # 新增类对应的 smali
   │  install_java_smali.sh  拷进 src/smali（同名冲突保护：tmp/java_owned.txt）
   ▼
src/                      # apktool 工程（含改动过的原版 smali / 资源）
   │  build_lx.sh          apktool b → zipalign → apksigner
   ▼
signed.apk
```

- 工具链：JDK 17、`apktool-cli.jar`、`platforms/android-30/android.jar`、`androidx.appcompat` stub jar
- 校验：`verify_rebuild.py` 比对重建版与原版的类/资源差异（「仅重建版」数量需等于预期值）
- 本机跑脚本的注意点：
  - 路径全 ASCII；bash 用 Git 自带的 `bash.exe`
  - `javac -encoding UTF-8`，控制台打印中文/符号前必须 `PYTHONIOENCODING=utf-8 PYTHONUTF8=1`，否则 GBK 控制台抛 `UnicodeEncodeError`
  - PowerShell 里包 bash 脚本一律用单引号，避免 `$?` 被提前展开

### 改造约束（踩过的坑）
1. 原版 `view id` 由 `public.xml` 钉死，**不能改**；新 id 用 `@+id/...`，Java 侧用 `getIdentifier` 按名取。
2. `?attr/...` 只能出现在颜色位；写成 `android:drawable="?attr/..."` 会崩。
3. 主题有 8 套 overlay，新增颜色必须走 `app_*` attr 才能跟随主题。
4. 新增 Activity 必须在 `AndroidManifest.xml` 注册。
5. 同名 smali 覆盖需显式 `JAVA_SMALI_TAKEOVER=1`，正常流程靠 `tmp/java_owned.txt` 记账。

## 6. 已知限制

- 成品包使用 **Android Debug 签名**，仅供本机自测，请勿分发。
- 浅梦公式集的棱块是 **UF 缓冲**，与内置集 **UR 缓冲** 只有 40 个 case 是同一物理 case，其余为形式重标号；因此两套数据各自独立存储进度，不做强行映射。
- 分段趋势只画 `STATUS == 0` 的成绩，DNF / +2 的罚时无法归到某一段。
- 混合随机练习不占用每日新卡额度，三档评分照常写 SRS。
- 仓库不含图片素材（联想图、图标源文件）与成品 APK，重建需要自备原版 APK 与素材。
- 文档与注释中的坐标、日志均为 Pixel_3a_API_30（1080×2220）模拟器实测值，换机型需重新测量。
